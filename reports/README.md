# Generated analysis outputs

Run `python -m src.run_analysis` from the project root (or run all notebook cells) to populate this folder with dataset-specific outputs.

- `analysis_summary.md`: computed dataset overview, category-level churn patterns, segment summary, recommendations, and interpretation notes.
- `figures/`: churn distribution, boxplots, correlation heatmap, category churn-rate plots, and segment plots.
- `tables/`: overall metrics, segment summary, and churn-rate crosstabs.

These outputs are generated from the verified IBM source CSV. They are not prefilled with estimated or illustrative statistics.
